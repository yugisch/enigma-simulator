# Enigma Machine Simulator

Classic 3-rotor Enigma M3 simulator for the browser.

## Features

- Rotors I–V, reflectors B/C, ring settings, plugboard
- Correct stepping (including double-stepping)
- Type on your keyboard or click the on-screen keys
- Live plain / cipher strip above the machine
- Lampboard lights the encrypted letter

## Use

Open `index.html`. Set rotors, rings, reflector, and plugboard if you like, then type A–Z. Space adds a visual gap. Same settings + start positions decrypt the ciphertext.
